# 🚀 HYPER TOPUP - Online Digital Goods & Gaming Store

Welcome to the official repository for **HYPER TOPUP**, an independent online store focused on digital goods and gaming-related services.

## 🛠 Tech Stack & Features

- **Frontend:** HTML5, CSS3, Modern JavaScript
- **PWA:** Progressive Web App with Manifest & Service Worker
- **Authentication:** Firebase Authentication with Google
- **Backend/Data:** Google Apps Script and Google Sheets where applicable
- **Hosting:** GitHub Pages
- **Connection:** HTTPS
- **Services:** Gaming top-ups and selected digital goods
